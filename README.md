# Flappy-Bird-Godot
A Flappy-Bird-style game developed in Godot as a game development learning project.

Flappy Bird – Godot

About the Project

This project is a Flappy Bird-style game created using the Godot game engine as part of my computer graphics coursework.

The game was developed primarily by following a YouTube tutorial, which helped me become familiar with the Godot environment, game scenes, and basic game development concepts.

My Contributions

While the main game implementation follows the tutorial, I made a few modifications to personalize the project:

- Changed the Game Over message to Persian.
- Adjusted the position of the Game Over text within the game interface.

Technologies Used

- Game Engine: Godot
- Project Type: 2D Game Development

How to Run

1. Download or clone this repository.
2. Open the Godot game engine.
3. Select Import and locate the "project.godot" file.
4. Open the project and run the game.
